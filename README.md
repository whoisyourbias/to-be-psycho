# to-be-사이코패스 · to-be-psycho

**AI는 가이드하고, 코드는 내가 친다.**

만들고 싶은 기능부터 시작하는 Claude Code / Codex용 학습 스킬 패키지입니다. AI가 범위를 함께 정하고 필요한 개념, 다음 행동과 코드 리뷰를 제공합니다. 학습자가 소스와 테스트를 직접 작성하고 실행합니다.

## 현재 상태

v0 로컬 구현·검증을 마쳤습니다. 자동 테스트 139개가 통과했고, 현재 가이드·리뷰 행동 평가 45회에서 기록된 위반이 없습니다. 실패 기준선과 수정 전 결과도 보존했습니다. Node.js 22 이상, 외부 의존성 없음. 검증 실행 환경은 Linux / Node.js 24.19.0입니다. **Windows native / macOS의 Claude Code·Codex 조합은 모두 미검증**입니다. 설치 파일이 있다고 지원을 확정하지 않습니다. 정확한 상태와 한계는 [인수 기록](docs/acceptance.md), [지원 표](docs/support-matrix.json), [결정과 트레이드오프](docs/decisions-and-tradeoffs.md)를 확인하세요.

이 패키지는 별도 앱, UI, 실행 에이전트나 정답 차단 보안 필터가 아닙니다. 모델 지침의 준수와 실제 호스트 권한에 의존합니다.

## 시작하기

1. [설치 안내](install/README.md)에 따라 신뢰하는 소스에서 호스트 배포물을 만듭니다. 설치 예정 경로/충돌을 검토하고 승인한 계획만 적용합니다. 기존 정책·설정·동명 스킬은 덮어쓰지 않습니다
2. 호스트에서 skill 발견과 실제 권한을 확인합니다: [Claude](adapters/claude/README.md), [Codex](adapters/codex/README.md). 상태 영역만 쓰도록 제한할 수 없으면 읽기/텍스트 안내와 수동 저장을 사용합니다
3. “learning-with-to-be-psycho로 장바구니 수량 선택 기능을 배우고 싶어. 코드는 내가 작성할게”처럼 목표와 현재 저장소를 알려 줍니다
4. 목표·범위·완료 기준을 합의한 뒤 현재 단계만 진행합니다. 질문하거나 힌트를 받았다는 이유로 진도를 넘기지 않습니다
5. 직접 작성한 변경분의 리뷰를 요청합니다. 학습자가 테스트를 실행해 명령·환경·시점·대상 코드 스냅샷과 비밀을 제거한 결과를 제출합니다. 오래된 로그는 현재 통과로 간주하지 않습니다
6. 리뷰 결과와 남은 미검증 사항을 확인하고 다음 단계 진행을 선택합니다. 실행 미검증 상태는 진행을 선택해도 그대로 남습니다

## 지원하는 학습 관점

HTML/CSS/JavaScript, Vue(필요 시 Nuxt 경계), React(필요 시 Next 경계), Java/Spring 기초, Spring MVC, Spring WebFlux를 참조합니다. Spring Boot는 MVC와 WebFlux가 함께 쓰는 공통 모듈입니다. 실제 버전과 의존성은 저장소에서 확인하며 고정 커리큘럼을 강제하지 않습니다. 이 목록은 학습 관점이며 모든 프레임워크/버전의 실기 검증을 뜻하지 않습니다.

## 재개·상태·복구

[상태 계약](core/state-format.md)은 `.to-be-psycho/state.json` 하나에 합의 범위, 단계, 시도, 공개 힌트, 스냅샷, 제출 근거와 리뷰를 저장합니다. `.to-be-psycho/` 제외는 .gitignore에 직접 추가하세요. 자동 수정하지 않습니다.

재개할 때 프로젝트 신원, 스키마, 패키지·프로필 버전과 현재 스냅샷을 검증합니다. 공급자를 바꿔도 진도/힌트 이력을 초기화하지 않습니다. 읽기 실패나 손상을 빈 상태로 덮어쓰지 않습니다. 충돌·기존 lock은 중단합니다.

복구는 정상 백업의 SHA-256을 확인하고 사용자가 명시적으로 승인한 뒤 `recoverState(root,{confirmed:true,backupSha256})`로 수행합니다. 손상 원본을 별도 보존합니다. 실제 쓰기 권한이 검증되지 않았다면 수동 저장/복구를 선택하세요. 업데이트·제거 절차는 [설치 안내](install/README.md#3-업데이트--제거)를 따릅니다.

## 무엇을 하지 않나요?

- 학습자 소스/테스트 작성·수정·자동 실행
- 현재 과제의 완성 코드, 전체 테스트나 교체 패치 제공. 여러 힌트를 합친 정답도 제한합니다
- 이해도 점수, 불이익, 필수 사후 평가 에이전트
- 사용자 정책/설정 변경, 자동 충돌 병합, 동시 학습 세션
- 실행하지 않은 테스트 통과, 검증하지 않은 독립 리뷰나 OS 지원 주장

개념과 이유, 디버깅 설명은 충분히 제공합니다. 독립 리뷰어가 없으면 같은 계약의 메인 순차 리뷰라고 명시합니다.

## 개발·검증

```sh
npm test
```

Node builtin test runner만 사용합니다. 별도 npm install은 필요하지 않습니다. [행동 평가 방법](tests/evals/README.md)과 [rubric](tests/evals/rubric.md)은 구조 검사와 행동/권한 검증을 구분합니다. `install/package.mjs`는 함수 라이브러리이며 실행 명령을 받는 CLI가 아닙니다. 승인된 [설계](docs/superpowers/specs/2026-10-02-to-be-psycho-design.md)와 [계획](docs/superpowers/plans/2026-10-02-to-be-psycho.md)을 보존합니다.
