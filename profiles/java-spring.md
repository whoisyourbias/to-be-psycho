# Java / Spring foundations · profile version 1

## Repository checks
Read build.gradle or pom.xml, wrapper/lock/version catalog files, actual Java toolchain, Spring versions and declared dependencies. Distinguish required framework features from installed libraries.

## Concepts
Types and nullability, objects and responsibilities, exceptions, collections, dependency injection and configuration, only as prerequisites for the feature.

## Review questions
Where is ownership/validation defined? Which exception contract is observable? Are dependencies injected at an appropriate boundary? Is a proposed API valid for the declared Java/Spring version? Avoid turning this into a mandatory foundations course.
