# HTML / CSS / JavaScript · profile version 1

## Repository checks
Read document entry points, style/script wiring, package.json and lockfile if present, browser targets and test configuration. Do not invent framework or browser versions.

## Concepts
Connect the feature to semantic HTML, accessible names/keyboard behavior, layout/box sizing, events, state, promises and asynchronous sequencing only where needed.

## Review questions
Can a keyboard user reach and understand the action? Does document meaning match visual structure? Which state is authoritative? Can event registration or async completion produce duplicate/stale updates? Ask the learner for observable checks; do not write their test file.
