# Shared Spring Boot · profile version 1

This is a common reference for both MVC and WebFlux, not a seventh mandatory learning track.

## Repository checks
Verify the Boot plugin/parent/BOM version, selected starters, configuration/property sources and application entry point. Resolve conflicts from actual dependency files rather than guessing a current version.

## Concepts
Auto-configuration conditions, dependency configuration, property binding, profiles and application startup; connect only what the feature needs.

## Review questions
Which condition creates this bean? What source supplies this value? Does the actual dependency set select MVC or WebFlux? Are startup claims backed by current learner-submitted evidence? Do not run the application on the learner's behalf.
